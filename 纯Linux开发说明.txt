【MaxKB 纯 Linux 内部开发（最终方案）】

一、唯一主开发目录
  路径: /home/tlx/projects/MaxKB
  说明: 以后只在这个目录开发、安装依赖、运行项目。

二、这套目录实际占哪块盘
  你的 Ubuntu-22.04 虚拟盘在: D:\wsl\ubuntu\ext4.vhdx
  因此本目录、.venv、data、tmp 等主要占 D 盘，不再新增一套到 C 盘。

三、当前虚拟环境
  目录: /home/tlx/projects/MaxKB/.venv
  进入方式:
    source .venv/bin/activate

四、启动 Web
  cd /home/tlx/projects/MaxKB
  bash scripts/dev-linux-home.sh
  浏览器访问:
    http://127.0.0.1:8080

五、Celery（如需要）
  cd /home/tlx/projects/MaxKB
  bash scripts/celery-linux-home.sh

六、数据库 / Redis
  仍由 Docker Desktop 提供
  Postgres: 127.0.0.1:15432
  Redis:    127.0.0.1:16379

七、Docker 数据现在在哪里
  已迁到: D:\DockerDesktopData\wsl
  原来 C:\Users\tlx\AppData\Local\Docker\wsl 只是联接，不再存放真实大文件

八、重要原则
  1. 不要再去 /mnt/d/porject/github/MaxKB 里 pip install
  2. 不要再去旧目录运行 main.py
  3. 旧目录只作为备份，主开发始终用当前目录
