# 客服分诊与升级处理 SOP

## 1. 目标

本 SOP 用于指导客服和一线技术支持统一处理售后咨询、故障报修和工单升级。

## 2. 首问必采集信息

客服接到客户问题时，必须先收集：

1. 客户名称
2. 产品型号
3. 设备序列号
4. 故障码或异常现象
5. 问题发生时间
6. 当前是否影响生产或业务
7. 联系人和电话

## 3. 问题分诊规则

### 3.1 知识咨询类

适用问题：

- 保修政策咨询
- 安装流程咨询
- 产品功能说明
- 常见故障解释

处理方式：

- 优先通过知识库标准答复
- 对涉及政策和流程的问题，回答时应引用正式文档

### 3.2 远程排障类

适用问题：

- 设备报码
- 通信异常
- 温度异常
- 首次校准失败

处理方式：

- 指导客户执行标准排查步骤
- 同时创建工单并记录排查动作

### 3.3 升级处理类

适用问题：

- 重复报码
- 高优先级客户投诉
- 设备停机影响业务
- 一线排查无结果

处理方式：

- 立即升级二线工程师
- 必要时安排现场支持

## 4. 时效要求

- 普通咨询：15 分钟内首次响应
- 高优先级工单：10 分钟内升级判断
- 影响生产的紧急工单：30 分钟内给出处理方案

## 5. 工单关闭前核验

关闭工单前应确认：

1. 客户问题已解决
2. 已记录故障原因
3. 已记录处理动作
4. 如涉及更换配件，已登记配件信息
5. 已邀请客户进行满意度评分

## 6. 典型问答

### 问：什么时候应该升级给二线？

如果一线排查超过 30 分钟仍无结果、同一故障重复出现、客户现场影响生产，应该升级给二线。

### 问：知识咨询是否需要建工单？

普通政策或安装咨询可不立即建工单；如果客户反馈实际故障或需要排查，应创建工单并记录过程。
