# 本地运行 MaxKB（源码 + Docker 数据库）

## Redis 密码与 YAML 写法

- `config.yml` 里 **`REDIS_PASSWORD` 冒号后面必须有空格**，例如：`REDIS_PASSWORD: "123456"`。  
  若写成 `REDIS_PASSWORD:123456`（无空格），YAML 可能解析错误，应用会拿不到密码，连 Redis 失败。
- 密码须与 Docker 启动 Redis 时的 `--requirepass` **完全一致**。

## 前置条件

1. **Docker**：已启动容器（示例名 `maxkb-postgres`、`maxkb-redis`），端口与 [config.yml](../../config.yml) 一致（本仓库为 `15432` / `16379`）。
2. **Python**：仓库根目录已创建 `.venv`（Python 3.11），且已安装依赖。
3. **配置**：根目录 `config.yml` 中 `DB_*`、`REDIS_*` 指向本机映射端口。

## 启动 Web（日常最常用）

在仓库根目录执行：

```bash
mkdir -p data/hf data/embedding tmp && ./.venv/bin/python main.py dev web
```

或使用脚本（等价）：

```bash
chmod +x scripts/start-dev-web.sh   # 首次
./scripts/start-dev-web.sh
```

启动成功后浏览器访问：**http://127.0.0.1:8080/**（具体路径以安装为准，常见会重定向到登录或管理端）。

## 前端（Vue）改动后看不到界面更新？

`dev web` 发的是 **`ui/dist` → collectstatic → `apps/static`**，不是直接读 `ui/src`。  
仓库根执行 **`./scripts/build-ui-static.sh`**（内含 `npm install`、双端构建、collectstatic），再重启 Web 并强刷；细节与最少步数见 **[09_本机启动与前端构建说明.md](./09_本机启动与前端构建说明.md)**。

## 必看：知识库「向量化」一直排队

向量化、部分同步任务由 **Celery Worker** 执行。只开 Web **不开 Celery** 时，文档会长期显示 **排队中**。

在 **第二个终端**（与 Web 分开）进入仓库根目录执行：

```bash
cd /path/to/MaxKB && ./.venv/bin/python main.py dev celery
```

或：

```bash
./scripts/start-dev-celery.sh
```

保持该窗口运行；停止时在该窗口 **Ctrl+C**。修改 `config.yml` 后建议 Web 与 Celery **都重启**。

## 可选：Celery（其它异步任务说明）

与上节为同一进程；日常本地开发建议 **Web + Celery 两个终端常开**（仅浏览页面可只开 Web）。

## 本次环境说明

- `main.py` 对 `HF_HOME`、`TMPDIR` 使用 **`setdefault`**：若未设置环境变量，则落在仓库内 `data/hf` 与 `tmp`，避免硬编码 `/opt/...` 在本地不存在。
- 若遇 `scripts/*.sh` 在 Windows 复制后出现 **CRLF** 导致 bash 报错，可用 `dos2unix` 转换，或直接用上面一行 `python main.py dev web` 命令。

## 停止服务

在运行 Web 的终端按 **Ctrl+C** 结束进程即可。
