## 你要亲自做的：最少步数（日常）

下面假设仓库在 **`~/projects/MaxKB`**，请改成你的路径；终端在 **WSL**（与跑 Python 同一环境）。

| 顺序 | 做什么 |
|------|--------|
| **A** | **仅第一次或换电脑时**：`node -v` 主版本必须 **≥ 20**。不够就装 Node 20（见下方「一次性」）。 |
| **B** | 仓库根目录执行一行：**`./scripts/build-ui-static.sh`**（已包含 `npm install`、两端 `vite build`（**已加大 Node 堆内存，缓解 OOM**）、`collectstatic`）。 |
| **C** | 正在跑 Web 的那个终端：**Ctrl+C** 停掉，再执行：`mkdir -p data/hf data/embedding tmp && ./.venv/bin/python main.py dev web` |
| **D** | 浏览器打开管理端地址，**Ctrl+Shift+R** 强刷一次。 |

**日常改完前端要看效果 = B + C + D 三步**（A 只做一次）。

> **AI / Cursor 不能替你做的**：不能操作你本机已打开的浏览器、不能在你没开的终端里替你按 Ctrl+C、也不能替你安装系统级 Node。能替你省掉的是：不必再手动 `cd ui`、不必分开记 `build-only` / `build-only-chat` / `collectstatic`，**一条脚本全跑完**。

## 一次性：Node 版本（出现 `await` / `Unexpected reserved word` 时必做）

任选一种，做完后**重开终端**，再执行 `node -v` 确认 ≥ 20。

**nvm（Linux / WSL 常用）**

```bash
curl -fsSL https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.1/install.sh | bash
# 重开终端后：
cd ~/projects/MaxKB/ui && nvm install && nvm use
```

**或** 打开 [https://nodejs.org](https://nodejs.org) 安装 **20 LTS**（Windows 本机开发时选 Windows 安装包；代码在 WSL 则要在 **WSL 里**装 Node，不要混用两套 Node）。

## 为什么不像「纯前端项目：改代码 → 刷新」？

你以前写的多半是：**浏览器直接连 Vite / Webpack 开发服务器**（`npm run dev`），改的是内存里的编译结果，所以保存就刷新就有。

本仓库你常用的是：**只起一个 `python main.py dev web`**。这时浏览器连的是 **8080 上的 Django**，它发的是磁盘上已经 **打好包** 的文件（`ui/dist` → `collectstatic` → `apps/static`），**不会**在每次请求时编译你的 `.vue`。所以多了一步「把源码打成包」——脚本就是为这一步服务的。

若想接近「保存即看」：可长期多开一个终端，在 **`ui` 里 `npm run dev`**，用 Vite 的端口调页面（代理已指向本机 API），与「直接打开 8080 看集成」是两条线，按需选用。

## `build-ui-static.sh` 已替你自动做的事

1. 检查 Node 主版本 ≥ 20  
2. **`npm install`**（不必再单独记一步）  
3. **`npm run build-only`**（管理端）  
4. **`npm run build-only-chat`**（对话端）  
5. **`python main.py collect_static`**（写入 `apps/static`）

## 其它常见「没变」

| 现象 | 处理 |
|------|------|
| 构建报 `JavaScript heap out of memory` | 脚本与 `ui/package.json` 的 `build-only*` 已带 **`--max-old-space-size=8192`**；仍爆可在运行前执行 `export NODE_OPTIONS=--max-old-space-size=12288`，或给 WSL 在 Windows **`.wslconfig`** 里多加内存后 `wsl --shutdown` 再开。 |
| 标题 / 外观仍像旧的 | **系统设置 → 外观**里若曾保存过，会覆盖默认；改完保存。 |
| 怀疑没打上新包 | `grep -o '<title>[^<]*</title>' ui/dist/admin/index.html` 看标题是否已更新。 |

**DEBUG 下**：`apps/maxkb/urls/web.py` 已改为开发时每次请求重新扫描 `apps/static` 下的资源列表，减少「只 collectstatic、列表仍旧」的边缘情况；**index.html** 本身每次请求都会从磁盘读。
